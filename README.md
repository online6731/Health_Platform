# ServiceOS — شبکه خدمات هوشمند

نسخه چهارم پروژه، بازتعریف کامل محصول به‌عنوان شبکه‌ای تلگرام‌اول از دستیارهای عمومی و تخصصی هوش مصنوعی است. هوش مصنوعی خدمات سطح اول را مستقیم ارائه می‌دهد و در صورت نیاز، کاربر را به متخصص یا کسب‌وکار واقعی تأییدشده متصل می‌کند.

> `ServiceOS` نام کاری محصول است و نام تجاری نهایی محسوب نمی‌شود.

## نسخه زنده

`https://online6731.github.io/Health_Platform/`

## صفحات اصلی

- `/#/` — چشم‌انداز و مدل شبکه
- `/#/services` — کاتالوگ باز فرصت‌های سرویس
- `/#/services/1` — PRD دستیار چندوجهی عمومی
- `/#/services/2` — PRD دستیار پوست، مو و زیبایی
- `/#/services/3` — PRD مشاوره اولیه پزشکی و آزمایش
- `/#/business` — ثبت، ویترین، جستجو، رزرو و مدیریت لید کسب‌وکارها
- `/#/roadmap` — فازبندی و گیت‌های تصمیم
- `/#/investor` — تز سرمایه‌گذاری و معماری درآمد
- `/#/trust` — سیاست ایمنی، داده، اعتبارسنجی و تبلیغات

## اصول محصول

1. تعداد سرویس‌ها ثابت نیست؛ فهرست فعلی نقشه فرصت است.
2. سرویس بعدی فقط پس از اثبات تقاضا، ایمنی و اقتصاد سرویس قبلی ساخته می‌شود.
3. تلگرام کانال شروع است؛ هسته داده و عامل‌ها مستقل از کانال طراحی می‌شود.
4. سطح اول توسط AI انجام می‌شود؛ سطح دوم با متخصص یا کسب‌وکار واقعی تکمیل می‌شود.
5. پیشنهاد تجاری پس از پاسخ اصلی، با برچسب شفاف و بدون اثر بر تصمیم ایمنی نمایش داده می‌شود.

## توسعه

```bash
npm install
npm run dev
npm run check
```

`npm run check` شامل lint، تست‌های محصول و build تولیدی است.
